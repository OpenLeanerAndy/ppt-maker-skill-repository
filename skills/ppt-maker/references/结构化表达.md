# 结构化表达规则

本规则用于决定“同一份内容应该用什么视觉结构表达”。目标是保留信息完整性的同时，让读者先看到结论和结构，再阅读细节。结构化表达不是装饰，也不是把每句话都改成卡片。

## 1. 先识别信息关系

在设计页面前，为每个模块标注一种主要信息关系：

| 信息关系 | 识别信号 | 首选表达 |
|---|---|---|
| 关键指标 | 数值、单位、占比、目标值、完成量 | `metrics` 指标组；必要时补结论提示 |
| 指标与明细 | 总量/分类统计后跟逐项记录 | 上方指标组，下方完整表格 |
| 异常或风险 | 退出、延期、调整、未完成、风险、差距 | `callout` 语义提示；红色只用于异常含义 |
| 并列事项 | 多项内容均具有“事项名 + 说明” | `matrix` 事项矩阵或子模块网格 |
| 行动计划 | 多项任务具有类别、动作、时间、责任、状态等稳定字段 | `matrix` 任务矩阵或表格，不用长项目符号列表 |
| 对比/趋势 | 多组数值、阶段变化、排名、构成 | 图表或表格 |
| 流程/阶段 | 有先后顺序、里程碑、输入输出 | 时间轴、步骤流或阶段表 |
| 纯叙述 | 同质、无稳定字段、无数值关系的解释性内容 | 段落或项目符号；需说明为何不适合结构化 |

同一页可以组合多种表达。例如“指标组 + 异常提示 + 明细表”或“指标组 + 结论提示 + 事项矩阵”。

## 2. 禁止退化为纯文字列表的条件

满足任一条件时，不得把整个模块仅做成正文或项目符号：

1. 同一模块含 3 项及以上“标签：说明”或“事项名 + 说明”的并列内容；应使用 `matrix` 或表格。
2. 同一模块含 2 个及以上需要比较、并列阅读或与目标值对照的关键数字；应使用 `metrics`、图表或表格。
3. 同一模块含类别、任务、时间、责任、状态、对象、方式、导向等至少两个稳定字段；应使用任务矩阵、键值子模块或表格。
4. 页面包含总量、分类统计和明细记录；应先呈现总量/分类指标，再呈现完整明细，不得只保留一张明细表或一段总述。
5. 源文存在退出、调整、延期、风险、差距等语义；应使用独立 `callout`，不能埋在普通段落或表格脚注中。
6. 一个内容页所有模块均只由正文或项目符号构成，但源内容存在上述结构；该页视为结构化表达验收失败。

纯文字列表只适用于同质的解释性条目。确实不适合图、表、指标或矩阵时，在页面填写非空 `visualExemptionReason`，或在单个模块填写非空 `plainListReason`；理由必须说明信息为何没有稳定字段或视觉比较关系，不能只写“内容较少”“保持简洁”。

## 3. 信息层级和页面组合

- 页面标题回答“本页讲什么”；`summary`回答“结论是什么”；模块回答“由哪些部分证明”。
- 关键数字应按“值—单位—标签”拆开，目标值和实际值应并列，不要把“55%（目标50%）”藏在一行说明中。
- 指标卡是信息入口，不是正文容器。指标后的原因、对象、方式、导向等说明使用 `matrix`、`callout` 或表格承接。
- 有明细表的项目推进页，优先采用“指标组—异常提示—明细表”的纵向层级；表格仍须保留全部字段。
- 行动计划页按业务板块分模块，模块内按任务名称拆成 `matrix` 子项；各子项保留原文动作、时间、责任和状态。
- 同页模块内容量明显不同时，使用不同宽高或 `module.layout`，不得机械等分后让长列表拥挤、短模块留下大片空白。
- 结构化之后仍须遵守 10 号正文、边界、表格完整性和源文保真规则；不得以“可视化”为由删减或改写内容。

## 4. 大纲阶段记录

页面大纲除标题和素材外，至少记录：

- `主要关系`：指标、指标与明细、异常、并列事项、行动计划、对比、流程或纯叙述。
- `首选表达`：指标组、表格、图表、图片、事项矩阵、提示块、时间轴或纯文字。
- `组合顺序`：例如“指标组 → 异常提示 → 明细表”。
- `例外理由`：只有选择纯文字且本页没有其他结构化证据时才填写。

用户确认大纲后，生成阶段不得擅自把已确认的指标、矩阵、提示或表格降级为普通文字列表。

## 5. 验收

逐页检查：

- 是否存在“有稳定标签的多项内容，却只用项目符号”的模块。
- 是否把目标值、实际值、占比、总量等关键数字埋入段落。
- 是否遗漏风险、调整或异常提示。
- 是否只保留明细表，却没有源文中的总量和分类统计；或只保留指标，却丢失明细。
- 是否因为机械等分导致模块留白过大、文字拥挤或层级消失。
- `matrix`、`metrics`、`callout`、表格和图表是否均在所属模块及页面边界内。

内置脚本会检查内容页是否包含结构化证据，并识别明显的“标签：说明”长列表。审计通过不等于视觉验收通过，仍须渲染全部页面逐页查看。
