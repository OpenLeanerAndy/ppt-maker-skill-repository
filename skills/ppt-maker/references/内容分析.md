# 内容分析规则与步骤

## 1. 分析内容结构
    - 提取材料中的所有级别的标题，创建材料的结构关系树
    - 提取材料中的关键结论和主要观点，记录到结构关系树的对应部分
    - 提取材料中每个关键结论和主要观点的论据，记录到结构关系树的对应部分
    - 提取材料中的图片、表格、图表、关键数据等信息，记录到结构关系树的对应部分
    - 为每个一级标题、必需结论、风险/否定表述、表格和媒体分配稳定的唯一id，并记录源文件及源位置
    - 表格必须记录正文行数、逻辑列数、表头行数、行表头列数、完整表头二维结构、正文二维矩阵、合并关系和最左侧字段；不得只记录视觉上较显眼的列
    - 表格必须标记原始行列方向；源文件已有表格时默认`orientation: source`，禁止为排版转置
    - 媒体必须记录总数、格式、尺寸及其所属标题，不能只提取文字说明而忽略原图
    - 按标题层级和源文档连续顺序建立`contentGroups`。每组记录`sourceRefs`、`sourceOrder`、`keepTogether`、`preferredFlow`；默认保持单页和源阅读方向

## 2. 素材形式转化
    - 完整读取[结构化表达.md](./结构化表达.md)，按其中的信息关系表为每个模块标注首选表达和组合顺序；本文件不重复定义指标、矩阵、提示块和图表的选择条件。
    - 评估是否需要为观点、结论、论据配图。如需配图，则制作。
        - 仅在有配图可以方便理解的时候设置配图。
        - 配图应尽量使用真人、原创人物、公共领域素材或已获授权素材等绘制，尽量不要采用抽象符号。
        - 配图使用.jpg或.png格式，绝对不要使用svg。
        - 配图尺寸根据[布局定义.md](./布局定义.md)的要求设置。

## 3. 生成内容分析结果
    - 以表格的形式整理完整记录：
        - 第一列：一级标题
        - 第二列：二级标题
        - 第三列：三级标题
        - 第四列：主要观点或结论（一行一条，一个标题内可能包含多条）
        - 第五列：论据（一个观点/结论对应一个论据单元格，多条论据用无序列表的形式展示）
        - 第六列：材料（一个观点/结论对应一个材料单元格，记录该观点/结论对应的论据数量、图片数量、表格数量、数据图数量、数据卡数量等）

## 4. 生成源内容清单
    - 按[内容保真与验收.md](./内容保真与验收.md)创建`sourceManifest`
    - 所有需要出现在PPT中的文字、表格和媒体默认标记为必需；确需省略时记录`omittedReason`并在大纲确认阶段说明
    - 页面大纲中的每个内容模块必须引用对应的`sourceRef`或`sourceRefs`
    - 不得先概括原文再反推清单；清单必须直接从完整源文件产生
    - 内容组的容量估算、单页重排和拆页授权统一执行[内容保真与验收.md](./内容保真与验收.md#5-容量和拆分)
