# 风格定义的规则

## 页面样式定义
1. 页面尺寸比例固定为16:9。
    - 如果输出格式为HTML格式，需保证每一个页面可以在全屏模式下一屏内显示完全。
    - 如果输出格式为png图片格式，可向用户进一步确认尺寸。默认情况下仍未16:9。
2. 边框与内容位置
    - 正文页内容控制在左侧0.3-0.7英寸、右侧0.4-0.7英寸、顶部1.15英寸以下、底部页码以上的区域内显示。
    - 正文页标题位于左上方，通常从横向约0.55-0.65英寸处开始，纵向约0.4英寸。
    - 正文内容通常从纵向约1.15英寸处开始；大型表格或框架可延伸到距页面底部约0.35-0.55英寸的位置。
    - 版面可以紧凑，但不能碰到 Logo、页眉分隔线或右下角页码。
3. 模块间距
    - 相邻内容块之间保持约 0.15-0.3 英寸的间距，一级内容块之间间距更大。



## 颜色定义
1. 页面整体配色
    - 页面整体采用白色背景，强调色为深蓝色(#0B2791)、浅蓝色(#009ADD)。
    - 标准文字颜色为灰黑色(#262626)，强调文字颜色为深蓝色(#0B2791)，注释等非主要文字为浅灰色(#666666)。
2. 配色特征描述
    - 白色占最大面积，保证高信息密度页面仍然清爽。
    - 蓝色是唯一稳定主色，用于建立层级、结构和企业识别。
    - 蓝色不是单一色值，而是从深蓝、中蓝、亮蓝到浅蓝形成完整层级。
    - 灰黑色用于主要文字，蓝色用于关键词、模块名和结构标签。
    - 红色只作为语义性例外，用于突出重点、风险、储备、调整或不同类型，面积明显小于蓝色。
    - 页面中的灰色主要承担弱化作用，例如目录页的非当前章节，不能替代主蓝色。

## 文字样式定义
1. 字体
    - 所有文字采用“思源黑体”(Regular粗细)，不使用其它字体。如系统内未找到，则优先使用本Skill内置的[思源黑体](../assets/fonts/SourceHanSansSC-Regular.otf)。
    - 如无法使用内置的[思源黑体](../assets/fonts/SourceHanSansSC-Regular.otf)，则在获得用户明确同意后，为用户安装字体到操作系统。
    - 首页标题、各页标题、各模块标题、各模块的子模块标题、数据图/数据表标题、关键数字、关键结论等文字加粗显示，其余文字不加粗。
2. 字号
    - 所有文字的字号采用如下几级设定，只允许使用下面列出的字号：
        - 34号字：首页标题文字、结束页文字
        - 24号字：各页标题、目录页大纲内容文字
        - 14号字：页面内各模块标题文字、数据图/数据表标题文字
        - 10号字：页面内各模块的子模块标题文字、所有正文文字、数据图/数据表内文字
    - 上述字号指最终渲染后的实际字号。不得使用自动缩小功能把10号正文或表格文字继续缩小；内容过量时调整布局或分页。
3. 行距
    - 所有文字的行距均为1.3倍

4. 颜色
    - 首页
        - 标题文字为深蓝色(#0B2791)
        - 非标题文字为灰黑色(#262626)
    - 目录页、章节标题页
        - 标题文字为深蓝色(#0B2791)
        - 目录中当前标题的颜色为灰黑色(#262626)
        - 目录中非当前标题的颜色为浅灰色(#666666)
    - 内容页
        - 标题文字的颜色为灰黑色(#262626)
        - 各模块的标题文字颜色为白色，背景色为深蓝色(#0B2791)，即标题为反色效果
        - 文字内容的颜色为灰黑色(#262626)，特别强调的数字等颜色为深蓝色(#0B2791)或红色
    - 结束页
        - 文字为深蓝色(#0B2791)
5. 对齐方式
    - 页面标题、正文左对齐。尤其是长段文本，一定要左对齐，不要居中对齐。
    - 模块、子模块的标题居中对齐

## 表格样式定义
1. 顶部表头（有可能为一行或多行）、左侧表头（有可能是一列或多列）的样式
    - 文字：10号字，1.3倍行距，粗体，白色。在水平方向与垂直方向均居中显示。表头文字后有括号加单位名称的(如"（元）")需要换行显示。
    - 背景颜色：#4472C4
    - 表格拆分为多个表左右显示或跨页显示时，每个表格都需要有相同的表头。
2. 表格内容（除表头以外的单元格）的样式
    - 文字：10号字，1.3倍行距，灰黑色(#262626)
    - 文字对齐方式：默认左对齐。纯数字列(包含整数、小数、百分数等)文字右对齐(不包括表头)。
    - 背景颜色：#EAEFF7
3. 小结、总结行的样式
    - 文字：10号字，1.3倍行距，灰黑色(#262626)，粗体。
    - 文字对齐方式：默认左对齐。纯数字列(包含整数、小数、百分数等)文字右对齐(不包括表头)。
    - 背景颜色：#4472C4
4. 特别说明：
    - 表格完整性、结构核对、单页重排和拆页授权执行[内容保真与验收.md](./内容保真与验收.md#4-表格结构保真)中的表格规则及“容量和拆分”规则；样式调整不得删除或遮挡内容。
    - 调整单元格内边距和行高，使文字不贴边但也不浪费空间。
    - 行高根据该行换行最多的单元格计算，不使用统一平均行高强行容纳长文本。
    - “单元格优选不超过2行”及相应列宽再分配只在初次生成后的视觉验收阶段执行，具体按[成品表格单元格行数优化](./内容保真与验收.md#成品表格单元格行数优化)处理，不得阻断前期生成。

## 数据图、图片样式定义
1. 用户提供的原文件里有数据图、图片
    - 对数据图、图片不要做任何修改，原样显示
    - 尺寸根据该模块当前内容的区域调整，缩放时要保持原图比例不变。放置在对应区域后图片周围可留白。
2. 用户提供的原文件里有数据表
    - 按[内容保真与验收.md](./内容保真与验收.md#4-表格结构保真)提取并核对原表，在对应区域按“表格样式定义”重新绘制。
3. 用户提供的原文件中没有所需的数据图、数据表或图片
    - 根据"内容分析"的结果，如有必要把内容绘制成数据图、数据表、图片等形式，方便用户理解，则可以按照上述要求的形式制作，并插入到页面的对应部分。
    - 绘制图片仍需使用背景色为纯白色的模板或样式，且绝对不允许使用svg格式。
4. 特别说明
    - 图片不得压住内容框上边线，也不得超出下边框。
    - 图表较小但比例正确时，优先调整模块宽度或高度，不以变形换取填满效果。
    - 同一章节中的两张图如果都属于一个子模块，应共同放在该子模块内，不能为了平衡版面随意移到其他子模块。
    - 图表上方应有模块标题和一句结论；下方或旁边可补充必要说明，不能只放一张孤立图片。

## 模块样式定义
1. 各模块均需有一个标题区域和模块内容区域。其中：
    - 模块的标题文字颜色为白色，背景色为深蓝色(#0B2791)，即标题为反色效果
    - 模块的内容区背景颜色为白色，边框为浅蓝色(#009ADD)，该模块的所有内容都放置在模块的内容区内（尤其需要注意文字、图片、表格、图表都在内容区内）
2. 各模块内部还可以再放置多个子标题，要求：
    - 子标题的文字颜色为深蓝色(#0B2791)，在子标题下方增加同样颜色的下划线。
    - 子标题在模块内居中显示。
    - 同一个模块里有多个子标题的，子标题显示效果相同。
    - 子标题下放置该子标题的内容。所有子标题及其内容都在其所属的模块的内容区域边框以内。

## 指标卡定义
- 指标卡应服务于“数值—单位—解释”的快速阅读。
- 数字不得压在卡片上边线，单位和说明不得超出卡片下边框。
- 指标卡整体必须位于模块内容区内。
- 如果源文主要是过程性文字，而不是需要突出的大数字，应使用逐条说明，不应强行改造成指标卡。
- 同一页的卡片大小、数字字号、上下间距应统一。

## 事项矩阵与提示块定义
- 事项矩阵用于“事项名 + 说明”或“任务 + 时间/责任/状态”等重复结构。每个子项使用统一的标题条、边框、内边距和10号正文；长文本左对齐。
- 矩阵应以层级和对齐提升可读性，不使用大面积装饰性色块，也不得把一句话拆成低信息量海报卡片。
- 结论提示使用主蓝色强调；风险、调整、延期、退出等异常提示可使用红色强调。红色只表达语义异常，不能作为随机装饰色。
- 提示块中的标签与正文必须同时完整显示，且与后续明细保持明确的阅读顺序。

## 其它说明
1. **框架先于装饰。** 视觉效果来自对齐、分组、色阶和边框，而不是图片装饰。
2. 所有列、行、标题条、边框和文字基线必须严格对齐；同层模块的间距、标题条高度和内边距应一致。
